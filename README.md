# CSE Student Portfolio

## Files
- index.html — portfolio content
- style.css — design and responsive layout
- script.js — mobile navigation
- resume.pdf — add your own resume here

## Personalize before publishing
Search `Your Name`, `yourusername`, `youremail@example.com`, and `Your College Name`
in `index.html` and replace them with your details.

## Publish on GitHub Pages
1. Create a GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and your `resume.pdf`.
3. Open Settings → Pages.
4. Choose the `main` branch and root folder.
5. Save. GitHub will provide your portfolio URL.
